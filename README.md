# Little Bull — Static Website

A multi-page HTML/CSS study project presenting a fictional software company, its sample portfolio and contact information.

## Pages

- `index.html` — home page
- `quem_somos.html` — about the company/team
- `portfolio.html` — example project cards
- `contato.html` — contact page

## Technology

- HTML5
- CSS3 (including page-level styling)
- Local image assets for the mock company and portfolio illustrations

## Running

Open `index.html` in a browser or serve the folder through a local static web server. No backend is required.

The company and portfolio examples are illustrative content for a front-end exercise, not a record of commercially deployed products.
